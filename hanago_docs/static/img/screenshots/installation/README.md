## How to Take Screenshots

**Windows shortcut:** `Win + Shift + S` (Snipping Tool)

**Tips:**
- Crop to show only the relevant area
- Use red circles/arrows to highlight buttons
- Resolution: 1280x720 or 1920x1080
- Format: PNG
- Name files exactly as listed above
