# Authentication

GreenCart includes a **complete login flow** — from first launch through password recovery.

---

## Auth Flow

```
App Launch → Splash Screen
                ↓
        First time? → Onboarding → Welcome
        Returning?  → Home Screen (auto-login)
                ↓
            Welcome Screen
           ↓           ↓
         Login       Register
           ↓           ↓
       [Success]   [Success]
           └─────┬─────┘
                 ↓
             Home Screen

Forgot Password:
Login → "Forgot Password?" → Enter Email → OTP → New Password → Login
```
