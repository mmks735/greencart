# Product Catalog

GreenCart's product catalog lets users browse, search, filter, and view product details.

---

## Category View

The main browse screen with 8 grocery categories.

- Grid layout of category cards
- Tap a category to see its products
- Sub-category filters within each category

## Product List

Products displayed in grid or list view.

### Features
- **Grid/List toggle** — switch between 2-column grid and list view
- **Search** — real-time search as you type
- **Filter drawer** — filter by category, price, rating, availability
- **Sort options** — by price, newest, rating, or popularity

### Product Card Shows
- Product image
- Name and weight
- Price (with discount if available)
- Star rating
- Wishlist heart icon
- Add to cart button

## Product Details

Full product detail page with everything a customer needs.

### Sections
1. **Image Gallery** — swipeable product images with zoom
2. **Product Header** — name, brand, rating
3. **Price** — current price, original price, discount percentage
4. **Variant Selector** — choose weight or size (250g, 500g, 1kg)
5. **Stock Status** — In Stock / Low Stock / Out of Stock
6. **Description** — full product description
7. **Related Products** — similar items
