## What is GreenCart?

**GreenCart** is a production-ready Flutter grocery e-commerce template designed to give developers a clean, fully-featured starting point — without starting from scratch.

It covers the entire user journey: onboarding, authentication, product browsing, AI-powered shopping assistance, cart & checkout, order tracking, and profile management. Everything is built on a consistent dark-green design system, with GetX powering a well-structured, scalable state management layer.

:::tip Who is this for?
GreenCart is ideal for developers and teams who want a **polished, maintainable codebase** they can customize and launch quickly — rather than building a grocery app UI from zero.
:::

---

## At a Glance

| Capability | Details |
|------------|---------|
| **Screens** | 32 fully designed UI screens |
| **AI Assistant** | Voice chat, recipe suggestions, and smart product recommendations |
| **Localization** | 9 languages — English, German, Spanish, French, Italian, Indonesian, and more |
| **State Management** | GetX — reactive state, controllers, and bindings |
| **Design System** | Manrope typography, consistent color tokens, dark-green theme |
| **Responsiveness** | `flutter_screenutil` — adapts seamlessly to all screen sizes |
| **Liquid Glass UI** | iOS 26-style liquid glass rendering via `liquid_glass_renderer` |
