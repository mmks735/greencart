## When You Write to Us

Help us help you faster! Include:

- Your **purchase code** (from CodeCanyon Downloads)
- **Flutter version** (`flutter --version`)
- **What happened** vs. **what you expected**
- **Error message** (copy from terminal)
- **Screenshots** if possible

## What We Help With

| We'll Help | We Won't |
|------------|----------|
| Template bugs | Custom development |
| Setup issues | Third-party services (Firebase, etc.) |
| "How does this work?" | Learning Flutter from scratch |
| Compatibility issues | Bugs from your custom code |
